1. Use the current Minecraft release

Open the official Minecraft Launcher and select the latest Java Edition release.

  1. Open Minecraft Launcher
  2. Select Java Edition
  3. Choose the latest release profile
  4. Click Play
2. Use the vanilla client
  1. Use the latest Java Edition release profile
  2. No Fabric, Forge, plugins, or server mods are required
  3. Join with an unmodified vanilla client

The server runs Mojang's official vanilla Java server.

3. Connecting to the Server
  1. Click Multiplayer on the main menu
  2. Enter the server address shown above and click Connect
  3. If the server is sleeping you'll see "Server is waking up! Reconnect in ~30 seconds." — just wait and reconnect
4. Server Notes
  • Previous world, mod, plugin, and loader data are archived on the Railway volume during the first vanilla boot.
  • The active server starts with a fresh vanilla world and no bundled mods or plugins.
  • Use the admin command box to run console commands such as op playername.
5. Server Rules
  • Be respectful to other players
  • No griefing or stealing
  • The server auto-shuts down after 10 minutes with no players to save hosting costs
  • Just connect to the server address and it will wake up automatically
