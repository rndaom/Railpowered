1. Install Minecraft 1.2.5

The default server is vanilla Java 1.2.5. Latest Minecraft cannot join.

  1. Open the official Minecraft Launcher
  2. Create a new installation and pick release 1.2.5
  3. Or use Prism/MultiMC with 1.2.5 and the Betacraft proxy betacraft.ee:11707
2. Connecting
  1. Click Multiplayer and enter the address above
  2. If the server is sleeping you will be kicked with a wake message — wait about 30 seconds and reconnect
  3. Ask an admin to whitelist your exact player name first
3. Changing version later
  • Use this panel. You do not need to change Railway variables for a version switch.
  • Vanilla, Fabric, curated Forge (1.7.10 / 1.12.2 / 1.16.5), and uploaded modpacks are supported.
  • Worlds from other versions are not reused automatically. Pick or create a world for the new version. Shared world folders work for Fabric and Forge, including nether/end.
4. Server notes
  • Old Fabric and beta data on the Railway volume is archived, not deleted.
  • The server auto-stops after 10 minutes with no players.
  • Be respectful. No griefing or stealing.
