# Security

If you find a problem that could let someone into a dashboard or a world they should not reach, please report it privately.

Use [GitHub Security Advisories](https://github.com/rndaom/Rail-Powered/security/advisories/new) on this repository.

Do not open a public issue for that kind of report.

When you deploy your own server:

- Use the generated `ADMIN_KEY` from Railway Variables, or set your own
- Do not share the dashboard URL with a key in the link
- Keep Railway variables private
