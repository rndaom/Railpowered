# Contributing

Thanks for helping.

1. Open an issue first if the change is large.
2. Keep the default path simple: latest vanilla Minecraft, one Railway template deploy, a dashboard for everything else. Do not send the Deploy button at a GitHub URL.
3. Do not add personal worlds, keys, or mods to the repo.
4. Run `python3 -m unittest tests.test_runtime` before you open a pull request.
