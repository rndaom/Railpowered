# Beta 1.7.3 Archive

This directory preserves the retired Project Poseidon / CraftBukkit beta setup.

- `plugins/` contains the old Poseidon plugin source.
- `templates/map.html` is the old WebMap UI that depended on the archived plugin stack.
- `poseidon.yml`, `server.properties`, `ops.txt`, `whitelist.txt`, and `PLUGIN_DEV_REFERENCE.md` are kept for rollback/reference.

The active Railway deploy now runs vanilla Minecraft 1.2.5. This folder is reference-only.
