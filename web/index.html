            Help
            
              
            How your friends join, what sleeping means, and what to do when something looks wrong.
            
            
            
          
            

          
            
            
            
              
            How friends join
            
              
            
                
              
                  
            1. Open Minecraft: Java Edition
              In the launcher, pick version the server's version. Bedrock (console and phone) can't join.
              2. 
                  
            2. Add the server
              Multiplayer, then Add Server, then paste the join address.
              3. 
                  
            3. Join
              If the server is asleep, the first try says it's waking up. Wait about a minute and join again.
              4. 
                
            
              
            
            
            

            
            
              
            Sleeping, explained
            
              
            
                
            When nobody has been online for a while, Railpowered saves the world and stops Minecraft. That frees most of the memory and CPU you pay Railway for.
            
                
            While it sleeps, Railpowered keeps listening on the join address. The next time someone joins, it starts Minecraft again on its own. You can also press Start here at any time.
            
                
            Sleeping is turned off, so the server stays on until you stop it. Turn it on in Settings.
            
                
            You can change the timer, or turn sleeping off, in Settings.
            
              
            
            
            

            
            
              
            Changing versions safely
            
              
            
                
            Give each new version its own world. That's the default in New setup.
            
                
            Minecraft can upgrade a world to a newer version, but it can't take it back. If you try to open a world on an older version than it was last played on, Railpowered stops you and offers a new world instead.
            
                
            Before you upgrade a world you love, back it up.
            
              
            
            
            

            
            
              
            Backups
            
              
            
                
            A backup is a copy of one world. Restoring it replaces that world, and Railpowered first saves a safety backup of the world as it is right now, so a restore never loses anything.
            
                
            Restoring never touches your setups, settings or player lists. Backups live on the same volume as the worlds, so download the important ones.
            
              
            
            
            
          
            

          
            
            
            Troubleshooting
            
            
            
              
            
                The join address is empty
                
            
                  
            Railway gives the server a public address through a TCP proxy on port 25565. The one-click template adds it for you. If you deployed another way, open your service in Railway, go to Settings, then Networking, and add a TCP proxy for port 25565. The address appears on the Overview after the next deploy.
            
                
            
              
            
              
            
                My friend sees "Outdated client" or "Outdated server"
                
            Their launcher version has to match the server exactly. The server runs Minecraft the version shown on the Overview. In the Minecraft launcher, open Installations, create one for that version, and play with it.
            
              
            
              
            
                Friends can't connect at all
                
            
                  
            Check the address has no typos and includes the port after the colon. If the server is asleep, the first attempt only wakes it, so wait a minute and try again. If the whitelist is on, make sure they're on it in Players.
            
                
            
              
            
              
            
                I forgot the admin key
                
            
                  
            If you set ADMIN_KEY on your Railway service, that's your key: open the service, then Variables. If you didn't, Railpowered generated one and printed it once, in the logs of the service's first deploy.
            
                  
            Either way, setting ADMIN_KEY under Variables replaces the key. Railway redeploys, you sign in with the new key, and everyone else is signed out.
            
                
            
              
            
              
            
                The server crashed
                
            The Overview shows the last useful line Minecraft printed, and the Console has the full log. Out-of-memory errors usually mean the modpack needs more RAM than your Railway plan gives the service.
            
                  
            If Minecraft crashed after it was online, the next friend who joins wakes it again. If it failed while starting, joining doesn't wake it for 5 minutes. When a retry can't help (for example Java is missing, or the world was played on a newer version), joining doesn't wake it at all until you start it from the Overview, switch setups or restore a backup.
